Every site in the nanisoft.com family was built by a coding agent. None of
them was built by agents alone.

The honest description of the loop is this: a person decides what a thing
should be — the design, the copy, the honesty law, the order of work — and
writes that down well enough that an agent can execute it. The agent does the
typing: components, styles, tests, build fixes, the deploy plumbing. The
person reviews the diff, runs the site, catches what the agent could not see,
and sends it back. Round after round until the thing is true.

If you have worked with coding agents, none of that is surprising. What it
adds up to, though, is the gap the company exists to close. The loop works,
but nothing about it is repeatable yet. Every run started with a hand-built
environment, a prompt standing in for a specification, and a diff reviewed in
a terminal. The capability was real; the factory around it was not.

[Nexus](https://nexus.nanisoft.com) is the factory. It turns that improvised
loop into a system: issues in, fresh containers per issue, planning before
code, suites before claims, and a Kanban board where a human approves, asks
for changes, or rejects — with three rounds of feedback as the ceiling, after
which the loop closes rather than spinning.

These five sites are what directed agents can do with a person holding the
standard. The factory is how that stops depending on the person's stamina.
