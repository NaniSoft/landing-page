Most companies ship products. NaniSoft is building the thing that ships
products.

The idea is not that agents can write code — that stopped being a claim a
while ago. It is that software creation has a shape: an idea arrives, a plan
is written, an architecture is agreed, the code gets built and tested, and
something merges. Humans run that shape today, and most of the running is
repetition. The factory's bet is that the repeatable ninety percent belongs
to machines that plan before they type, test before they claim, and stop when
the work needs judgment.

So the company has one product that matters and a discipline around it:

- **Nexus** is the Agent Factory — the orchestration engine that takes a
  GitHub issue and returns a reviewed, tested, merged change. It is in
  development, and everything we learn from shipping everything else goes
  into it.
- **Everything else** is the evidence. Atlas, AlphaLens, and Prism are real
  products with real sites, and they were all built the way Nexus will build:
  a person directing, agents building, suites gating every change.

This site, the company root, is part of the evidence too. Five sites, one
design language, one component library — and a factory underneath it that is
slowly learning to run without hands.
